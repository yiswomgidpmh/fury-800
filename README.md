## Overview

Fury-800 is an 8-voice polyphonic synthesizer delivering warm, analog-inspired sounds through dual oscillators, a ladder filter, and a simple yet expressive modulation section.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Fury-800** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Oscillators** | Sawtooth, square, and pulse waveforms with hard sync and detune |
| **Ladder Filter** | Moog-style 4-pole low-pass filter with resonance and self-oscillation |
| **Poly Mode** | 8-voice polyphony with voice steal modes for dense chords |
| **Mod Envelope** | Dedicated modulation envelope with adjustable ADSR targeting filter |
